\PanelHead{\ColA}{\RowA}{01}{The idea: SONIC for a small humanoid}
\Par{64}{460}{941.33}{25}{34}{ink}{NVIDIA SONIC showed that a single policy can track almost any human motion, but it was built for the larger Unitree G1 and trained on a large GPU cluster. We asked whether a lab with one GPU can have the same kind of tracker on a small robot. So we ported SONIC to the Booster K1, trained it from scratch on one GPU, fixed it for the real robot, and released everything.}
